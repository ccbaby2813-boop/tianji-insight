## 快速开始

### 新开发者入职

1. 阅读 [架构文档](./architecture.md) 了解项目整体架构
2. 阅读 [SOP 规范](./sop.md) 了解开发流程
3. 根据分工阅读 [前端开发文档](./frontend.md) 或 [后端开发文档](./backend.md)

### 日常开发

1. 查看 [SOP 规范](./sop.md) 的检查清单
2. 根据修改类型查阅对应文档
3. 提交前对照检查清单逐项确认

### 应用市场上架

1. 阅读 [上架发布方案](./release.md) 明确渠道/支付分叉
2. 阅读 [运维文档](./ops.md) 的部署流程、[微信多端应用官方说明书](./微信多端应用官方说明书.md) 的打包与上架要点
3. 按 [上架发布方案](./release.md) 第 6、7 节的清单与推进计划执行
4. 更新 [历史修改记录](./changelog.md)

### 提示词调整

1. 阅读 [AI 推演提示词文档](./prompt.md) 了解完整提示词结构
2. 修改 `_backend_src/src/services/tuiyan.js` 中的提示词代码
3. 同步更新 [AI 推演提示词文档](./prompt.md)

## 项目概述

**天机推演**是一款基于《易经》六十四卦与奇门遁甲的 AI 文化解读工具。

- **产品形态**：微信小程序 + Android/iOS App（Donut 多端框架）
- **后端域名**：`https://claw-book.cn/tianji`
- **官网**：`https://claw-book.cn`（纯静态展示）
- **上架状态**：Android 已上架 **Google Play**（海外版，3.3.6）；国内各市场待上架

### 核心功能

- 命理推演（AI 生成个性化报告，普通推演扣积分：10 积分/次；深度推演 VIP 专享）
- 积分体系（签到/看视频/连签奖励/新用户赠分，普通推演扣积分）
- VIP 会员（虚拟支付 / H5 支付 / Google Play Billing）
- 64 卦卡牌收集 + 成就系统
- 易缘传书（易经人格匹配社交，话题模板促进通信）
- 节气养生（24 节气 + 卦格专属建议，节气变更当天 9:00 推送通知）
- 推送通知（匹配回应 / 信件到达 / 节气提醒）
- 三种分享（推演结果 / 匹配结果 / 个人人格，H5 落地页 + 深链唤起 App）
