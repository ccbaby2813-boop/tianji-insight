## 3. 多语言商店文案（A 类，撰写；上传需你确认）

优先级：`ja` → `ko` → `zh-TW`

统一策略：
- 名称保持品牌 + 品类词，如 `易経インサイト：性格診断`、`주역 인사이트: 성격 테스트`、`易經洞察：人格測驗`
- 短描述 ≤80 字符，必须包含本地语言的"本命卦/人格测试"对应词
- 长描述基于英文版翻译，不做逐字直译，保留功能事实与免责声明

交付物：`docs/play-listing-i18n.md`（11 种语言四字段全文 + 字符数核对）

### 上传受阻记录（2026-10-22 更新，结论已修正）

- 浏览器自动化三次尝试均在 Play Console「管理翻译」自定义组件处失败，改为走 Android Publisher API（`androidpublisher/v3` edits → listings.update → commit）。
- **服务账号权限**：`tianji-play-verify@tianji-insight.iam.gserviceaccount.com` 在 Console 的账号级与应用级均显示「管理员（所有权限）」。
- **2026-10-22 审核已通过**：公网商店页名称已变为 `I Ching Insight: Personality`（en/es/ar 均验证）。
- **但 commit 仍 403**，且对照实验排除了"审核锁"与"内容问题"：

| 实验 | 结果 |
|---|---|
| 空 edit commit（无改动） | ✅ 成功 |
| 11 种语言 PUT | ✅ 11/11 成功 |
| 11 种语言 commit | ❌ 403 PERMISSION_DENIED |
| 单语言 es-ES commit | ❌ 403 |
| en-US 内容原样回写后 commit | ❌ 403 |
| 仅改 `details`（联系方式相同值）后 commit | ❌ 403 |

- 结论：**空提交不触发权限校验；任何带改动的发布都会被 API 拒绝**。Console 显示 Admin 但 API 侧的发布权限未生效（疑似 app 级绑定过期/未同步），非审核锁、非 locale 代码问题、非脚本问题。
- 另尝试"保留未提交 edit 让 Console 显示草稿"：Console 商品详情的语言下拉仍只有 en-US / zh-CN，**API edit 不会出现在 UI**；该悬挂 edit 已删除，Play 上无任何残留。
- locale 代码实测：`ja-JP`/`ko-KR`/`zh-TW`/`es-ES`/`pt-BR`/`ar`/`fr-FR`/`de-DE` 可用；**`ru-RU`、`id`、`vi`** 正确，`ru`/`id-ID`/`vi-VN` 会被拒。
- **2026-10-22 重授权后解决**：将服务账号的应用级权限**移除并重新添加**为「管理员（所有权限）」后，`commit` 成功；11 种语言全部写入并送审，API 逐语种回读核对通过（标题/短描述/长描述均与文档一致）。
- 经验沉淀：
  1. 该 403 的根因是 **app 级权限绑定失效**，Console 显示 Admin 不代表 API 已认；重授即恢复。
  2. 空 edit 提交成功**不能**作为权限判据（无改动不触发发布校验）。
  3. Cloudflare 代理偶发返回空响应，脚本必须以 `GET listings` **回读校验**，不能依赖 PUT 的响应体。
  4. locale 代码必须用 Play 认的写法（`ru-RU` / `id` / `vi`）。
- 服务器保留 `gplay_fill_listings.js`（含回读校验与失败回滚）与 `gplay-listings.json`，可重复执行。

### 执行中修正的两个事实错误（重要）

1. **出生时辰是采集的、且参与计算**：实测建档页为「日期 + 时辰」双选择器（12 个两小时时段 + 不确定，默认 `11:00-13:00`），后端 `calculateGua(year, month, day, shichen)` 中下卦与动爻都含 `shichen`。首版落地页/llms.txt 曾写"不采集、不参与计算"，已改为"可选、未选默认 11:00-13:00"。
2. **本命卦按农历计算**：`_backend_src/src/routes/user.js` 先 `solarToLunarForGua` 再调 `calculateMingBenGua`。文案已补 `lunar calendar`，Play 描述同步修正并重新送审。

### 部署运维要点（本次实测发现）

- 线上 nginx 用正则 `location ~* ^/([a-z0-9-]+)\.en\.html$ → alias /var/www/tianji-tuiyan/content/$1.en.html`，**英文页必须放到 `content/` 目录**，放站点根目录不会生效。
- 本次首轮误按仓库相对路径上传到根目录，产生 205 个文件名含反斜杠的垃圾文件，已全部删除；根目录原有 12 个副本已从备份还原。
- 备份命名：`*.bak-20261021`（首轮）/ `*.bak-20261021b`（文案修正轮）。
