问题清单与修复建议

已修复问题

  • 高
    安全头被 Cache-Control 覆盖（80/86 页面缺失安全头）已修复
    nginx 的 add_header 指令不继承——server 级别配置了 HSTS/X-Frame/CSP 等安全头，但每个 location 块里的 add_header Cache-Control 会完全覆盖 server 级的所有 add_header，导致 80 个页面丢失全部安全头。
    修复：创建 /etc/nginx/snippets/security-headers.conf 共享片段，在 16 个有 add_header 的 location 块中 include 该片段。修复后 86/86 页面 5/5 安全头完整。

待修复问题（按优先级）

  • 中
    52 个卦页 meta description 过短（48 字，低于 50 字下限）
    gua-01 至 gua-64 中 52 个页面的 meta description 仅 48 字符，低于 SEO 推荐的 50-170 字范围。可能影响搜索结果摘要展示。
    建议：批量在 description 末尾补充"，仅供文化参考与自我探索。"（+14 字），使总长度达到 62 字，落入推荐区间。
  • 中
    首页 & 英文首页 title 过短（16 字，低于 20 字下限）
    首页 / 和 /?lang=en 的 title 仅 16 字符，低于 SEO 推荐的 20-70 字范围。关键词覆盖不足。
    建议：中文首页 title 改为"天机推演 - AI易经人格解读 | 六十四卦本命卦性格测试"（约 28 字）；英文首页改为"I Ching Insight - AI I Ching Personality Reading | 64 Hexagrams"。
  • 低
    4 个协议页缺少 OG 标签和 JSON-LD 结构化数据
    /agreement、/agreement.en、/privacy、/privacy.en 四个页面缺少 Open Graph 标签和 JSON-LD 结构化数据。协议页通常不需要 SEO 排名，但补齐可提升完整性。
    建议：为协议页添加基础 OG 标签和 WebPage 类型 JSON-LD，或保持 noindex（协议页无需被搜索引擎收录）。
  • 低
    英文知识库索引页 title/description 过长
    /knowledge.en.html 的 title 为 77 字（超过 70 字上限），description 为 217 字（超过 170 字上限）。过长会被搜索引擎截断。
    建议：title 精简为"Knowledge Center - I Ching, Yi Jing & Hexagrams | I Ching Insight"（约 65 字）；description 精简至 150 字以内。
