问题清单与修复建议（按优先级）

高优先级（影响可访问性/合规）

  • 高
    84/86 页面缺少键盘焦点样式（:focus）
    全站仅 2 个页面有 :focus 样式。键盘导航用户（Tab 键切换）无法看到当前焦点位置，违反 WCAG 2.4.7 Focus Visible。这是可访问性最大短板。
    修复：在全局 CSS 中添加 a:focus, button:focus { outline: 2px solid #c9a96a; outline-offset: 2px; }，一行代码覆盖全站。

中优先级（影响转化/信任）

  • 中
    首页首屏无 CTA 下载按钮
    浏览器实测：打开首页后，首屏被太极星球大图占据，看不到任何下载按钮或 CTA。用户需要向下滚动才能找到下载入口。研究显示首屏 CTA 可提升转化率 20-30%。
    修复：在 Hero 区太极图下方或叠加一个"立即下载"金色按钮，或缩小 Hero 图比例让 CTA 进入首屏。
  • 中
    仅 7/86 页面 footer 有 ICP 备案号
    79 个知识库页面 footer 缺少 ICP 备案号（京ICP备16050769号-4）。国内合规要求经营性网站在页脚标注备案号，缺失影响信任度和合规性。
    修复：批量在 79 个知识库页 footer 添加 ICP 备案号链接（指向 beian.miit.gov.cn）。

低优先级（优化体验）

  • 低
    首页主导航放了"Delete Account"链接
    浏览器实测：首页顶部导航包含 Download / Knowledge / Sign in / Register / Delete Account / 中。"Delete Account"（注销账号）放在主导航不合适，容易误触，应该放在 footer 或用户设置菜单里。
    修复：从主导航移除"Delete Account"，保留在 footer（已有）和登录页内。
  • 低
    首页导航文字对比度偏低
    首页导航文字为浅灰色（#9a968c），在深色背景（#0a0a0f）上对比度约 4.0:1，略低于 WCAG AA 标准的 4.5:1（正常文本）。知识库页导航文字对比度正常。
    修复：首页导航文字颜色调亮至 #b8b4a8 或添加 hover 时变金色（已有）。
  • 低
    footer 链接偏少（平均 3.1 个）
    全站 footer 平均仅 3.1 个链接（服务协议/隐私政策/账号注销）。可以增加"关于我们""知识库""联系方式"等有用链接，提升站内互链和用户导航。
    修复：footer 增加"关于我们""知识库""联系方式"链接，分组展示。
  • 低
    英文知识库索引页缺少面包屑导航
    knowledge.en.html 没有面包屑导航（Home / Knowledge），而中文知识库页都有。英文用户无法快速返回上级页面。
    修复：在 knowledge.en.html 顶部添加面包屑导航（Home / Knowledge Center）。

审计方法说明

本次 UX/UI 审计采用代码批量扫描 + 浏览器实测走查双轨方法：
代码扫描：对 sitemap 中 86 个 URL 并发抓取，检查导航一致性、视觉层级、交互反馈、可读性、移动端、信任度、可访问性 7 大维度共 30+ 指标。
浏览器走查：用真实浏览器访问首页和知识库文章页，截图验证视觉效果、导航布局、CTA 可见性、排版舒适度，模拟用户核心任务路径。
参考标准：Nielsen 十大可用性原则、WCAG 2.1 AA、Maze UX Audit Checklist、WowMakers 50-point UX Audit、Heurilens UX Checklist。
