## 🚀 发布平台操作指南

### 知乎（中文）
1. 访问 https://zhuanlan.zhihu.com/publish
2. 登录账号
3. 点击"写文章"
4. 复制Markdown内容粘贴（知乎支持Markdown）
5. 添加话题标签：#易经 #AI #性格测试 #传统文化
6. 文章末尾保留官网链接
7. 发布

### CSDN（中文，技术向）
1. 访问 https://editor.csdn.net/md/
2. 登录账号
3. 点击"写博客"
4. 复制Markdown内容粘贴
5. 添加分类：人工智能、传统文化
6. 添加标签：AI, 易经, 大模型, 传统文化
7. 发布（选择"公开"）

### Medium（英文）
1. 访问 https://medium.com/new-story
2. 登录账号（可用Google账号登录）
3. 复制Markdown内容粘贴
4. 添加标签：I Ching, AI, Astrology, Personality, Philosophy
5. 文章末尾保留官网链接
6. 发布（选择"Public"）

### Reddit（英文，社区推广）
1. 访问相关subreddit：r/IChing, r/astrology, r/AIdev, r/philosophy
2. 不要直接发文章链接，先发讨论帖
3. 标题示例："What do you think about using AI to interpret the I Ching?"
4. 正文中简要介绍观点，末尾附上文章链接
5. 注意遵守各subreddit的规则
