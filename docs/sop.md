## 1. SOP 总则

### 1.1 核心原则

**小程序与 App 双端同步**：凡涉及页面 UI、交互、文案、样式、布局、API 字段读取的任何修改，**小程序与 App 通过 Donut 多端框架共用一套代码，天然同步**。

由于使用 Donut 多端框架，小程序代码会自动编译为 App，因此小程序和 App 只需维护一套代码。网页端（`web/index.html`）仅作官网展示 + APK 下载入口，非对齐目标，仅在官网文案/下载入口变更时才修改。

双端代码路径：
- 小程序/App（Donut 共用一套）：`tianji-tuiyan-miniprogram-v10/`
- 网页官网（独立维护）：`web/index.html`

参考 `docs/topology.md` 确认双端字段名一致。

### 1.2 适用范围

- 前端页面修改
- 组件开发
- 样式调整
- API 接口变更
- 数据库字段变更
- 文案修改

### 1.3 责任分工

| 角色 | 职责 |
|------|------|
| 开发者 | 按 SOP 执行修改、自查 |
| 代码审查 | 检查 SOP 执行情况 |
| 测试 | 双端验证 |
| 运维 | 部署发布 |

## 2. 双端同步规范

### 2.1 同步原则

小程序与 App 通过 Donut 共用一套代码，天然同步；网页官网独立维护，不在同步范围内。

| 修改类型 | 同步要求 |
|----------|----------|
| 页面 UI/交互/文案 | 小程序/App 共用一套代码，天然一致 |
| API 字段 | 双端字段名、类型、含义必须一致 |
| 样式类名 | 双端使用同一套样式体系 |
| 组件命名 | 双端组件命名规范统一 |

### 2.2 双端差异处理

| 功能 | 小程序端 | App 端 | 处理方式 |
|------|----------|--------|----------|
| 登录 | `wx.login` | `wx.weixinMiniProgramLogin` | 条件分支（Donut `#ifdef`） |
| 支付 | 虚拟支付 | H5 支付 | 条件分支 |
| 分享 | 原生分享 | Open SDK | 条件分支 |
| 视频播放 | 远程视频 | 远程视频（xweb） | 统一配置 |

### 2.3 代码示例

```javascript
// 双端登录逻辑（Donut 条件编译）
if (this.globalData.isMpWeixin) {
  // 小程序端
  wx.login({ ... });
  const loginPath = '/api/auth/login';
} else if (this.globalData.isApp) {
  // App 端
  wx.weixinMiniProgramLogin({ ... });
  const loginPath = '/api/auth/miniapp-login';
}
```

## 3. 代码修改流程

### 3.0 任务开始时（前置检查点）

动手写代码之前，必须用 TodoWrite 建立任务清单，并强制包含以下两项（与代码改动并列，不可省略）：
- 「更新对应文档」
- 「输出 SOP 执行摘要」

### 3.1 修改前

1. 确认修改范围（前端/后端/双端）
2. 查阅相关文档（`docs/` 目录）
3. 评估影响范围

### 3.2 修改中

1. 按照规范编写代码
2. 保持双端一致性
3. 添加必要注释

### 3.3 修改后

1. 对照检查清单逐项确认
2. 双端测试验证
3. 更新相关文档
4. 输出 SOP 执行摘要

### 3.4 完成定义（收尾检查点）

只有同时满足以下条件，任务才算完成：
- 代码改动完成且验证通过
- 对应文档已同步更新（禁止遗留到下一次对话）
- 回复末尾已输出 SOP 执行摘要

三者缺一不可；代码改完但文档未更新，一律视为任务未完成。

### 3.5 多轮修改挂账规则

- 「更新对应文档」「输出 SOP 执行摘要」两项 todo 必须保持未完成（pending）状态，不得提前标记完成或删除，直到真正执行完毕才标记 completed；
- 每轮回复结束前检查 TodoWrite 列表：若仍存在未完成的 SOP 收尾项，必须在回复末尾主动提醒用户，禁止静默结束回合。

## 4. 后端命名规范

### 4.1 接口命名

```
RESTful 风格：
GET    /api/resource          # 获取列表
GET    /api/resource/:id      # 获取详情
POST   /api/resource          # 创建
PUT    /api/resource/:id      # 更新
DELETE /api/resource/:id      # 删除
```

### 4.2 字段命名

- **数据库字段**：snake_case（如 `user_name`）
- **API 字段**：snake_case（如 `user_name`）
- **前端变量**：camelCase（如 `userName`）

### 4.3 错误码命名

- 大写字母 + 下划线（如 `INVALID_PARAM`）
- 语义清晰（如 `USER_BANNED`）

### 5.1 文档类型与更新时机

| 文档 | 更新时机 |
|------|----------|
| `docs/backend.md` | 后端接口/数据库修改后 |
| `docs/frontend.md` | 前端代码修改后 |
| `docs/algorithm.md` | 提示词/算法修改后 |
| `docs/ops.md` | 部署/配置修改后 |
| `docs/architecture.md` | 架构/模块改动后 |
| `docs/topology.md` | API 字段变更后 |
| 对应文档更新规则：API 改动 → `docs/topology.md`；架构/模块改动 → `docs/architecture.md`；前端改动 → `docs/frontend.md` |

### 5.2 更新要求

- 文档与代码保持同步，修改后立即更新，禁止遗留到下一次对话
- 重大变更需详细说明
- 示例代码需可运行

## 6. 部署验证流程

### 6.1 部署前检查

- [ ] 代码已提交到 Git
- [ ] 双端测试通过
- [ ] 文档已更新
- [ ] 数据库迁移脚本已准备（如有）

### 6.2 部署步骤

**后端部署**：
```bash
ssh admin@YOUR_SERVER_HOST
cd /home/admin/.openclaw/workspace/projects/tianji-tuiyan
git pull origin main
npm install --production  # 如有新依赖
pm2 reload tianji-tuiyan-api
pm2 logs tianji-tuiyan-api --lines 20
curl http://127.0.0.1:3003/api/health
```

**小程序部署**：
1. 微信开发者工具 → 上传
2. 微信公众平台 → 提交审核
3. 审核通过后 → 发布

**App 部署**：
1. 微信开发者工具 → 多端应用模式
2. 构建 Android/iOS
3. 上传应用市场

### 6.3 部署后验证

- [ ] API 健康检查通过
- [ ] 小程序功能正常
- [ ] App 功能正常（真机测试）
- [ ] 日志无异常错误

### 6.4 SOP 执行摘要

每次改动结束时（在回复正文中），必须输出以下四项：
- 改了什么文件
- 双端是否同步
- 文档是否更新
- 部署是否验证

某项不适用时（如纯文档改动）须明确写"不适用"，禁止留空。

## 8. 常见问题处理

### 8.1 双端不一致

**问题**：小程序和 App 表现不一致

**排查**：
1. 检查 `tianji-tuiyan-miniprogram-v10/` 中 Donut 条件编译代码
2. 检查 `docs/topology.md` 中字段名一致性
3. 检查 Donut 条件编译配置（`#ifdef MP-WEIXIN` / `#ifdef APP-PLUS`）

**解决**：统一代码逻辑，确保双端一致

### 8.2 代码包超限

**问题**：子包大小超过 2048KB

**排查**：
1. 检查 `project.config.json` 的 `packOptions.ignore`
2. 检查大文件（视频/图片）

**解决**：
- 大文件使用远程 URL
- 帧动画图片压缩到 500KB 以内
- 配置忽略不必要的文件

### 8.3 视频播放问题

**问题**：App 端视频遮挡按钮

**排查**：
1. 检查 `project.miniapp.json` 中 `xweb: true`
2. 检查 CSS 中 z-index 设置
3. 检查是否重新编译 App

**解决**：
- 确保 xweb 同层渲染开启
- 正确设置 z-index（video: 1, 按钮: 10+）
- 修改配置后重新编译 App

### 8.4 登录失败

**问题**：App 端登录报错 `-700000`

**排查**：
1. 检查多端应用是否绑定移动应用账号
2. 检查 `app.miniapp.json` 配置
3. 检查后端 `MINIAPP_APPID` 和 `MINIAPP_APPSECRET`

**解决**：
- 确保多端应用绑定移动应用
- 配置 `identityServiceConfig`
- 配置后端环境变量
