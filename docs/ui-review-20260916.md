## 1. 必须修复（高，3 项）

### H1 · 通知页三个图标在 icon-guo 表中不存在，渲染空白

- **位置**：`sub/profile/notifications/index.wxml:35,63`；对照 `components/icon-guo/icon-guo.js` 的 `icons` 对象
- **现象**：消息列表里 `letter_received` 用 `name="mail"`、`jieqi_reminder` 用 `name="leaf"`、系统通知用 `name="info"`，空态也用 `<icon-guo name="mail">`；但这三个名字在 icon-guo 的 SVG 表里 **grep 0 命中**，`getSvg()` 返回 undefined，图标位全空白。
- **修复建议**：在 `icon-guo.js` 补 `mail` / `leaf` / `info` 三个 SVG，或改用表中已存在的 `envelope` / `incense` / `flip` 等等价图标。

### H2 · 分享海报社交标签（# hashtag）胶囊可撑破画布

- **位置**：`components/share-poster/share-poster.js:210-238`
- **现象**：`var socialText = '#' + social; var socialWidth = ctx.measureText(socialText).width;` 后直接画圆角矩形，全程无截断；英文 hashtag 一长（如 `#PerfectlyAlignedCosmicEnergyMatch`），胶囊宽度 `socialWidth+24` 会超过 500px 画布，左右贴边甚至溢出。
- **修复建议**：按 `measureText` 结果循环截断单词，或硬性 `socialWidth ≤ w-80`，超出尾部加 `…`。

### H3 · 旧罗盘组件 `components/compass/` 是死代码

- **位置**：`components/compass/` 整目录；对照 `sub/learn/learn/index.json`（只注册了 `qimen-compass`）
- **现象**：全局 `.json` 无任何页面 `usingComponents` 引用 `compass/compass`，线上只跑新版 `qimen-compass`。旧版还硬编码中文数组（`compass.js:26-31` `['金','木','水','火','土']`），无 i18n，一旦被误引用英文态整盘中文。
- **修复建议**：确认无其他入口后删除该目录；若要保留则在 README 标注 deprecated。

## 2. 建议修复（中，17 项）

### M1 · 写信页信纸竖排水印写死中文"书/笺"

- **位置**：`sub/match/letter-write/index.wxml:71-72`
- **现象**：`<text class="vertical-char">书</text><text class="vertical-char">笺</text>` 硬编码；同项目 `letter-thread` 同位置已用 `{{t.vertical1}}{{t.vertical2}}`（en-US.js:789-790 译为 `LET`/`TER`）。英文用户在写信页会看到两个陌生汉字。
- **修复建议**：改为 i18n 变量，复用 letter-thread 的 key，或在 letter 命名空间补 `writeVertical1` / `writeVertical2`。

### M2 · 预置信件模板冒号硬编码全角"："

- **位置**：`sub/match/letter-write/index.js:214,223`；耦合处 `:471`
- **现象**：`buildPresetContent` / `buildTemplateContent` 返回 `` `${t.dear} ${receiver}：\n...` ``，冒号写死全角；英文 `t.dear="Dear"`（en-US.js:703），实际渲染为 `Dear John：`。`isPreset()` 正则 `/^[^：]*：/` 也硬编码全角冒号，耦合脆弱。
- **修复建议**：冒号按 `i18n.isEn()` 切半/全角（英文 `:`），`isPreset` 正则同步调整。

### M3 · 修改档案页英文"不确定"时辰回显中文

- **位置**：`sub/profile/edit-profile/index.js:6,64,88`
- **现象**：模块常量 `SC` 末项写死 `'不确定'`；`onShichen()` 里 `setData({ shichenLabel: SC[idx] })`、`loadProfile()` 里 `shichenLabel = SC[shichenIndex]`，都没用已本地化的 `SCLocalized`（applyI18n 里已把末项换成 `t.uncertain`）。英文用户 picker 里看到 "Not sure"，选完卡片上显示中文。
- **修复建议**：改用 `this.data.shichenOptions[idx]`（已本地化数组），不要直接读模块常量 `SC`。

### M4 · 奇门罗盘详情中文长文硬编码在组件内

- **位置**：`components/qimen-compass/qimen-compass.js:116-222`
- **现象**：约 100 行五行/八门/遁甲详情中文长文写死在组件 JS 里（如 `taichi: { title:'太极', desc:'太极是宇宙的本源...' }`），英文环境仅当 i18n 字典命中时翻译，未命中即整段中文 fallback。
- **修复建议**：长文详情迁入 `i18n/en-US.js` 与 `zh-CN.js`，组件内只存 key。

### M5 · 结果页奇门盘单元格"标签+吉凶徽标"英文拥挤

### M12 · 分享海报截断逻辑按字符数不准 + 卦名拼接无截断

- **修复建议**：统一改为 `measureText` 驱动的像素级截断（二分或逐词回退），卦名拼接也按像素宽度截断。
