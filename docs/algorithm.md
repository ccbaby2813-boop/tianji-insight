## 1. 命理算法概述

### 1.1 算法概述

天机推演的命理算法基于《易经》六十四卦与奇门遁甲理论，结合用户生辰信息计算**易经人格**，并调用 DeepSeek AI 生成个性化推演报告。

### 1.2 核心算法流程

```
用户输入生辰 + 问题
    ↓
农历转换（lunar-javascript）
    ↓
计算易经人格（上卦 + 下卦 + 动爻）→ 梅花易数
    ↓
确定易经人格（64 卦之一，如"飞龙者"）
    ↓
奇门遁甲排盘（注入时空变量）
    ↓
构建 AI 提示词上下文（buildRegularContext / buildVipContext）
    ↓
调用 DeepSeek API 生成报告
    ↓
保存推演记录 + 更新卦卡收集
    ↓
返回推演结果
```

### 1.3 提示词文档

**完整提示词原文**（System Prompt + User Prompt）见项目根目录：
- [AI推演提示词文档.md](../AI推演提示词文档.md) — 唯一权威文档，提示词与代码一字不差

本文档仅概述算法逻辑，不重复提示词内容。

## 2. 易经人格计算

### 2.1 计算原理

易经人格由上卦、下卦、动爻三部分组成，基于梅花易数算法：

- **上卦**：根据出生年份（地支数）+ 月份 + 日期计算
- **下卦**：根据出生年份（地支数）+ 月份 + 日期 + 时辰计算
- **动爻**：根据出生年份（地支数）+ 月份 + 日期 + 时辰计算

### 2.2 计算公式

```javascript
// services/algorithms.js

// 年地支数 = (year - 4) % 12 + 1
const yearDiZhi = ((year - 4) % 12) + 1;

// 上卦 = mod8(年地支数 + 月 + 日)，0 取 8
const upperGua = ((yearDiZhi + month + day) % 8) || 8;

// 下卦 = mod8(年地支数 + 月 + 日 + 时辰)，0 取 8
const lowerGua = ((yearDiZhi + month + day + shichen) % 8) || 8;

// 动爻 = mod6(年地支数 + 月 + 日 + 时辰)，0 取 6
const movingYao = ((yearDiZhi + month + day + shichen) % 6) || 6;
```

**核心函数**：`calculateMingBenGua(year, month, day, shichen)` / `calculateMovingYao(year, month, day, shichen)`
// 组合卦 ID = 通过二维表查找卦名，再映射到ID
const fullName = HEXAGRAM_TABLE[upperGua - 1][lowerGua - 1];
const guaId = HEXAGRAM_NAME_TO_ID[fullName];
```

**八卦数值映射**：1=乾, 2=兑, 3=离, 4=震, 5=巽, 6=坎, 7=艮, 8=坤

## 3. AI 推演系统

### 3.1 推演类型

天机推演提供两种推演：

| 类型 | 模型 | 输出格式 | 字数 | 并发 |
|------|------|----------|------|------|
| **普通推演** | `deepseek-v4-flash` | JSON（6字段） | ≤700字 | 每进程 100 并发 |
| **VIP 深度推演** | `deepseek-v4-flash` | 纯文本（7段落） | 1000-2000字 | 每进程 20 并发 |

### 3.2 提示词架构

两种推演的提示词均由 `buildRegularContext()` / `buildVipContext()` 函数构建，包含：

```
[角色设定 System Prompt] + [用户问题 + 算法变量 User Prompt] + [输出要求]
```

**完整提示词原文**见 [AI推演提示词文档](./prompt.md)。

### 3.3 AI 调用流程

```
阶段1：读数据（持有DB连接）→ 查询用户档案 + 积分/配额 → 释放连接
阶段2：构建参数（不持有连接）→ 计算易经人格 + 奇门排盘 + 构建提示词
阶段3：AI 调用（不持有连接）→ 调用 DeepSeek API（最长120s）
阶段4：写结果（重新获取连接）→ 保存推演记录 + 扣减积分/次数 → 释放连接
```

### 3.4 并发控制

```javascript
// 普通推演：每进程 100 并发 AI 调用，信号量超时 60s（全局 4 进程 400）
const regularSemaphore = new TuiyanSemaphore(100);

// VIP 推演：每进程 20 并发 AI 调用，信号量超时 180s（全局 4 进程 80）
const vipSemaphore = new TuiyanSemaphore(20);
```

### 3.5 安全过滤

**输入过滤**（5类恶意模式）：
1. SQL 注入关键字
2. XSS 攻击
3. Prompt Injection（英文）
4. 中文 prompt 注入
5. 角色模拟

**输出过滤**：
- URL/Script/iframe 标签过滤
- 广告/博彩等关键词过滤
- 字段长度限制（panCi≤50字，yiList/jiList每条≤15字）

## 4. 奇门遁甲排盘

### 4.1 排盘算法

核心函数：`services/qimen.js` 的 `calculateQimen(year, month, day, shichen, userGuaWuxing)`

**核心排盘算法**（v12.1 修复后）：

1. 节气 + 三元 → 定局（阳/阴遁 + 局数）
2. 排地盘三奇六仪
3. 日干支 → 日柱旬首；时干支（五鼠遁起时柱）→ 时柱旬首（**定值符星/值使门**）
4. 时柱旬首宫 → 原始值符星、原始值使门
5. 值符随时干：时干在地盘的位置 → 值符落宫
6. 值使随时支：从旬首宫起，飞(时辰-1)步 → 值使落宫
7. 排八神：值符神随值符宫，阳顺阴逆
8. 日干/时干落宫 → 所临八神

**附加信息计算**：

9. 详细信息（星门神宫的吉凶、含义、适宜）
10. 宫位 → 八卦（中五宫寄坤二宫）
11. 五行生克（用户易经人格五行 vs 局五行）
12. 节气含义

> **v12.1 关键修复**：原实现用**日柱**推旬首，导致值符星/值使门连续多天不变。修复后改用**时柱**推旬首，星门随时柱旬首循环（约10个时辰/20小时一变）。

### 4.2 关键常量

- 九星原始宫位：一蓬二芮三冲四辅五禽六心七柱八任九英
- 八门原始宫位：一休二死三伤四杜五(无)六开七惊八生九景
- 八神固定顺序：值符、螣蛇、太阴、六合、白虎、玄武、九地、九天
- 中五宫寄坤二宫（奇门遁甲规则）

## 5. 五行生克算法

### 5.1 五行关系

| 关系 | 含义 | 解读基调 |
|------|------|----------|
| 比和 | 同五行 | 同频共振，平衡 |
| 我生 | 用户生局 | 在付出消耗 |
| 生我 | 局生用户 | 得天助，可积极 |
| 我克 | 用户克局 | 可控但费力 |
| 克我 | 局克用户 | 风险最高，须谨慎 |

### 5.2 八卦五行

| 五行 | 对应卦 |
|------|--------|
| 金 | 乾、兑 |
| 木 | 震、巽 |
| 水 | 坎 |
| 火 | 离 |
| 土 | 艮、坤 |

### 5.3 生克关系

- **相生**：金生水 → 水生木 → 木生火 → 火生土 → 土生金
- **相克**：金克木 → 木克土 → 土克水 → 水克火 → 火克金

## 6. 合盘匹配算法

### 6.1 匹配原理

基于两人易经人格的五行生克关系，从 `config/relationship.js`（2080条关系数据）中查找匹配解读。

关系键归一化：`${Math.min(guaA, guaB)}-${Math.max(guaA, guaB)}`（A-B 与 B-A 返回相同结果）

### 6.2 匹配等级

| 关系类型 | 匹配等级示例 | 说明 |
|----------|-------------|------|
| 相生 | 天作之合 | 大吉 |
| 比和 | 默契搭档 | 吉 |
| 相克 | 互补碰撞 | 需磨合 |

## 7. 节气养生算法

### 7.1 三层数据架构

- **L1（通用层）**：24节气基础养生信息，来自 `solar_term_basic` 表或 `config/jieqi-health.js`
- **L2（规则层）**：25条五行关系规则矩阵，来自 `config/wuxing-relation.js`
- **L3（专属层）**：1536条卦格专属养生建议（64卦 × 24节气），来自 `solar_term_health_advice` 表

### 7.2 节气计算

```javascript
const { Lunar, Solar } = require('lunar-javascript');

function getCurrentJieqi() {
  const solar = Solar.fromDate(new Date());
  const lunar = solar.getLunar();
  return {
    jieqi: lunar.getJieQi(),
    name: JIEQI_NAMES[lunar.getJieQi()],
    date: solar.toYmd()
  };
}
```
