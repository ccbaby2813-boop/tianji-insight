## 1. 产品简介

### 1.1 什么是天机推演？

天机推演是一款基于《易经》六十四卦与奇门遁甲的 AI 文化解读工具。产品强调传统文化解读，而非算命/预测。

### 1.2 产品特色

- **传统文化**：基于《易经》六十四卦理论
- **AI 智能**：DeepSeek AI 生成个性化报告
- **双端可用**：微信小程序 + Android App（Donut 双端，共用一套代码）；网页为官网展示 + 下载入口
- **免费体验**：新用户注册赠 10 积分，每日签到 +10、看视频 +10（普通推演 10 积分/次）

### 1.3 适用人群

- 对传统文化感兴趣的用户
- 面临人生抉择需要参考的用户
- 喜欢探索自我成长的用户

## 2. 快速开始

### 2.1 下载与安装

**微信小程序**：
1. 打开微信
2. 搜索"天机推演"
3. 点击进入小程序

**Android App**：
1. 访问官网 `https://claw-book.cn`
2. 扫描二维码下载 APK
3. 安装并打开

> **注**：目前仅支持 Android 平台，iOS 版本开发中。

### 2.2 注册与登录

- **小程序**：自动微信登录，无需手动操作
- **App**：点击登录按钮，唤起微信授权

### 2.3 建立档案

首次使用需要建立个人档案：

1. 点击"我的"页面
2. 点击"建立档案"
3. 输入昵称、选择性别
4. 填写公历出生日期（年份范围 1900-当前年）
5. 选择出生时间段（时辰）
6. 同意使用协议
7. 点击保存

## 3. 核心功能

### 3.1 命理推演

**功能说明**：输入问题，AI 基于易经人格生成个性化推演报告。

**使用步骤**：
1. 点击首页的"易学解读"按钮（正面）或翻转到"深度解读"按钮（背面）
2. 输入您的问题（如"最近工作变动如何抉择"）
3. 点击"开始推演"
4. 等待 AI 生成报告（普通推演约 10-60 秒，超级推演约 30-120 秒）
5. 查看推演结果

**翻转按钮说明**：
- 正面"易学解读"：金色渐变（不再展示积分说明，积分体系详见「关于我们」页）
- 背面"深度解读"：深紫底金描边，显示剩余次数，VIP 专属
- 点击右侧"⇄"按钮触发 3D 翻转切换

**推演计费**（v17.1）：
- 普通推演（免费用户）：10 积分/次
- 普通推演（VIP 会员）：每日 20 次次数制，北京时间 0 点重置，用不完作废
- 积分获取：每日签到 +10、看视频 +10（小程序端）、连续签到每满 7 天 +100 并赠 1 次深度解读
- 积分不足时，弹窗引导"看视频 +10 / 去签到"

### 3.2 VIP 超级推演

**功能说明**：VIP 专属深度推演，注入全量算法变量（四柱、节气、奇门排盘、五行生克、八神等），提供更详细的分析。

**使用步骤**：
1. 成为 VIP 会员
2. 在首页翻转按钮切换至"深度解读"（背面），或通过 VIP 页面进入
3. 输入问题
4. 等待生成报告（约 30-120 秒，复杂情况可能更长）

**次数限制**：每日 1 次（支持按用户配置）

### 3.3 64 卦卡牌收集

**功能说明**：推演过程中自动收集卦象，集齐 64 卦解锁成就。

**查看方式**：
1. 点击"我的"页面
2. 点击"卦卡收集"
3. 查看已收集的卦卡

**成就解锁**：集齐 64 卦解锁"周天圆满"成就

### 3.4 易缘传书

**功能说明**：卦格匹配社交功能，找到与你卦格相合的朋友。

**使用步骤**：
1. 进入"易缘"板块，阅读并同意引言内容
2. 浏览匹配池候选人（每次展示 10 位）
3. 退出重进可刷新候选人列表
4. 点击"启封"查看匹配报告
5. 可以写信给对方

**写信功能**：
- 底部左侧"举报"按钮，右侧"寄出此笺"按钮
- 每个用户每天最多向同一人发送 3 封信
- 拉黑后双方互相不可见，不可重新匹配

### 3.5 节气养生

**功能说明**：24 节气通用养生 + 卦格专属养生建议。

**查看方式**：
1. 首页右侧半透明金色竖向拉杆（显示当前节气名+下拉箭头）
2. 点击拉杆，从右侧滑入节气详情浮层
3. 查看节气介绍、养生建议
4. 下滑查看卦格专属养生建议（含宜食、宜行、忌等）

### 3.6 分享功能（v3.6 三种分享 + 6 渠道）

**分享推演结果**：
1. 在推演结果页面点击"分享"
2. 选择分享渠道（微信 / WhatsApp / Facebook / Messenger / X / Telegram，App 端分享面板带真实 logo）
3. 好友点击链接打开落地页，看到**分享者当时的完整推演记录**（只读）；已装 App 的好友点击"打开 App"直接唤起对应结果页

**分享易缘匹配（匹配结果）**：
1. 在匹配结果页面点击"分享"
2. 落地页完整展示双方匹配结果（双卦+关系名+等级+分析/共鸣/冲突/建议），不依赖双方在线
3. 已装 App 的好友点"打开 App"唤起后看到的就是这份匹配结果

**分享个人人格（易经人格）**：
1. 在人格详情页点击"分享"
2. 落地页展示你的卦象人格；好友打开 App 后用自己的卦与你进行易缘匹配

> 微信内置浏览器打开落地页会被拦截"打开 App"，按页面引导点右上角"···→在浏览器打开"即可唤起。

## 4. 常见问题

### 4.1 账号相关

**Q：小程序和 App 的账号互通吗？**
A：是的，使用同一微信账号登录，数据完全互通。

**Q：如何绑定手机号？**
A：在"我的"页面点击"绑定手机号"，输入手机号和验证码即可。

**Q：忘记密码怎么办？**
A：本机推演使用微信登录，无需密码。如需绑定手机号，可在"我的"页面操作。

### 4.2 推演相关

**Q：每日推演次数什么时候重置？**
A：每日北京时间 0 点重置。

**Q：推演结果准确吗？**
A：推演结果基于《易经》理论和 AI 生成，仅供参考，不作为决策依据。

**Q：可以重新推演同一个问题吗？**
A：可以，每次推演都会消耗次数。

### 4.3 VIP 相关

**Q：VIP 会员有哪些权益？**
A：
- 每日 20 次普通推演（北京时间 0 点重置，用不完作废）
- 每日 1 次超级推演（深度解读）
- 专属深度报告
- 无广告

**Q：如何购买 VIP？**
A：
- 小程序：点击首页翻转按钮背面"深度解读" → 选择套餐 → 虚拟支付
- App：点击"我的" → "VIP 会员" → 选择套餐 → H5 支付
- 套餐：月卡 ¥19.9 / 年卡 ¥168

**Q：VIP 可以退款吗？**
A：虚拟商品不支持退款，请谨慎购买。

### 4.4 技术问题

**Q：视频加载失败怎么办？**
A：检查网络连接，或重启应用。

**Q：登录失败怎么办？**
A：
1. 检查网络连接
2. 重启应用
3. 清除缓存后重试

**Q：App 闪退怎么办？**
A：
1. 重启应用
2. 清除缓存
3. 重新安装 App

## 5. 隐私与安全

### 5.1 数据收集

我们收集以下信息：
- 微信 openid（用于身份识别）
- 生辰信息（用于推演计算）
- 推演记录（用于历史查看）
- IP 地址（用于安全监控）

### 5.2 数据使用

- 生辰信息仅用于推演计算
- 推演记录仅用于个人查看
- 不会向第三方出售用户数据

### 5.3 数据安全

- 使用 HTTPS 加密传输
- 数据库定期备份
- 敏感信息加密存储

### 5.4 用户权利

- 可随时查看个人数据
- 可申请删除个人数据
- 可随时注销账号
