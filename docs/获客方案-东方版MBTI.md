## 一、核心诊断：为什么之前没效果

之前的内容（官网 SEO/GEO、知乎/CSDN/Medium 技术文）吸引的是**开发者和 SEO 从业者**——他们不是来算命的，也不会分享给朋友。**问题不是渠道选错，是内容定位与目标人群错配。**

产品真正所在的流量池：
- **人格测试池**（MBTI 16 型 → 64 型更丰富）
- **玄学/星座/塔罗池**（小红书 15.9 亿浏览、TikTok #astrology 839 亿播放）
- **恋爱合盘/配对池**（4096 组配对 = 最强裂变武器）

**一句话定位转变**：「东方版 MBTI」——用易经 64 卦做人格分类、合盘做 CP 匹配。统一话术：**"不是算命，是认识自己的工具"**。

## 三、竞品共性（5 条可复用规律）

1. **免费测试工具 = 最低成本获客入口**，结果卡片 = 社交货币（16Personalities 全网话题数十亿）
2. **关系型功能（合盘/配对） = 最高效自然裂变引擎**（测测 6000 万用户靠分享卡片起家）
3. 变现是"免费 → 轻度付费 → 重度付费"三级漏斗
4. 平台算法推荐 + 社交热梗是引爆催化剂（陶白白 30 天涨粉近千万）
5. 垂直定位 + 长期信任积累比短期收割更可持续

## 五、分平台执行要点

### 小红书（第一主战场 · 纯人工）
- 恢复期 8 周：第 1-2 周纯生活回归（每周 1-2 条）→ 第 3-4 周兴趣切入（每周 2-3 条）→ 第 5-6 周软植入（每 3 条最多 1 条带产品暗示）→ 第 7-8 周稳定输出 + 合规引流
- 内容形式：图文图鉴（收藏率最高）、对比测试（转发率最高）、情感痛点（互动率最高）
- 引流：企业号留资工具 → 小红书店铺 → 评论区自然回复
- 🚫 全程手机 App 手动，不用任何第三方工具/脚本

### 抖音（增长放大器）
- 2026-09 玄学赛道大清洗，**站外引流永久封杀**；唯一合规路径 = 抖音小程序挂载 + 企业号主页官网链接
- 内容：文字卡/动画短视频 30 秒内展示"输入出生时间→卦象→人格解读"，每天 1 条（18:00-20:00）
- ⚠️ 对批量发布检测极严，内容必须差异化

### 知乎（长尾搜索 · 纯人工）
- 恢复期 2 周只浏览点赞；主攻争议题「易经算命准吗」「MBTI 到底准不准」，把易经定位为"古人的人格分类系统"
- **前 10 个回答不放任何外链**，引流靠个人简介
- 每周 2-3 个回答，不一天答 5 个

### 微信生态（裂变闭环基建 · P0）
1. H5/小程序测试页：输入出生时间 → 本命卦 → 精美人格海报（可截图分享）+ 二维码
2. 合盘裂变：测完引导"测你和 TA 的合盘"→ 邀请链接 → 朋友点开即进合盘页
3. 分享解锁：分享到朋友圈/群解锁深度报告
4. 公众号每周 2 篇深度内容；视频号同步短视频

### 海外
- **TikTok**（第一优先）：Pick-a-Pile 选卦型（暂停拉完播率）、"3 signs you're Hexagram 1"型；需 1000 粉挂链接，前期用 Linktree
- **Instagram**：Reels 每周 3-4 条一稿多发 + 64 卦人格卡片 Feed + Stories 互动
- **Reddit**（纯人工）：养号 2-4 周 → 先贡献价值 → 软性提及 → 链接只放 bio（90/10 规则）
- **Quora**（纯人工）：Google 长尾 SEO 价值极高，前 10 答不放外链

### Google Play ASO（上架前必须）
| 项目 | 要求 |
|---|---|
| Title（≤50 字符） | 前 30 字符含主关键词，如 "I Ching Reading · Hexagram Personality - Tianji" |
| Short Description（≤80） | 前 20 字符放核心关键词 + 价值主张 |
| Long Description | 首段钩子 → 功能 3-5 条 → 场景 → CTA，关键词自然重复 3-5 次 |
| 截图 5 张 | 第 1 张必为"输入时间→卦象"主界面；含人格详情、合盘、图鉴、信任背书 |
| Feature Graphic | 1024×500 |
| 评分目标 | 4.0+（进 featured 候选池门槛） |

**首发倒排**：T-6 周注册海外号 + 存 10 条视频 → T-4 周封测 + Reddit/Quora 养号 → T-2 周 ASO 定稿 + PH 养号 + pre-launch 300 人 → T-0 发布 + PH 发布（PT 00:01）→ T+1 周小预算 UAC 测试

## 七、合规红线（所有平台统一）

**做"文化/心理/娱乐"定位，不做"算命/改运/消灾"**：

| ❌ 禁止 | ✅ 安全替代 |
|---|---|
| 算命、占卜、改运、消灾 | 性格分析、人格画像、关系匹配 |
| 招财进宝、旺人旺财、逢凶化吉 | 幸运色、穿搭建议、文化解读 |
| 犯太岁、开光、加持 | 传统文化、国学、易经哲学 |
| "这个测试很准" | "仅供娱乐，认识自己的一种方式" |
| 直接引导加微信 | 平台官方留资工具/企业号链接 |

**自动化风险等级**：小红书/知乎/Reddit/Quora = 🚫 禁止自动化（全程人工）；抖音 = ⚠️ 高风险（内容必须差异化）；微博 = ⚠️ 中（官方定时 ≤2-3 条/天）；TikTok/IG = ⚠️ 中（排期可用但内容真实）；公众号/小程序 = ✅ 安全
